# PadLock Store
> Projeto de website desenvolvido em 2023 para uma loja independente de revenda de roupas.

## Sobre o projeto

Este projeto foi desenvolvido em 2023 com o objetivo de criar a primeira presença online de uma loja independente de revenda de roupas, originalmente administrada por meio do Instagram.

O desenvolvimento do website surgiu a partir de uma parceria com o responsável pelo projeto original, com a proposta de estruturar a apresentação dos produtos e criar uma experiência de navegação mais completa para os clientes.

O site foi desenvolvido utilizando WordPress e Elementor, com foco na criação das páginas, organização visual dos produtos e construção da identidade digital do projeto.

## Status

**Projeto arquivado / não concluído**

O projeto não chegou à etapa final de publicação e operação comercial. Durante seu desenvolvimento, a iniciativa original foi descontinuada e, posteriormente, a presença da loja nas redes sociais também deixou de ser mantida.

Por esse motivo, o website é apresentado neste repositório exclusivamente como registro do trabalho desenvolvido durante o projeto.
